## 复跑与取证

按[仓库首页](../../README.md#验证)准备 Redis、测试模型凭据和本机二进制，运行 `python tests/run_acceptance.py --evidence-dir <新目录>`。每个用例独立建立测试数据。汇总文件 `results.json` 记录二进制 SHA-256、每个断言组的结果及耗时。`http.jsonl` 按请求记录方法、路径、HTTP 状态、业务对象标识和请求响应摘要，可与测试夹具打印的计数交叉核验。

执行池对照使用同一台机器上的多个独立进程、共享 SQLite 和 HOME。吞吐与等待时间对应记录中的固定负载。生产部署容量需用目标机器和实际工具负载测量。总线替换的逻辑契约由模块测试验证，本期可部署的消息总线为 Redis Streams。
