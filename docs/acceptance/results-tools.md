测试用普通用户、另一用户、管理员、审批人及 CI 来源的独立身份发送 HTTP 请求。模型和 CI/MCP 使用本地受控 HTTP 服务，以便指定要测试的工具调用、阻塞或丢弃首个回执，并在接收方计数。测试后清理临时 HOME。可运行 `cargo build`，将 `LOOM_TEST_REDIS_URL` 指向可用的测试 Redis，再运行 `python tests/acceptance_catalog.py`；设置 `LOOM_TEST_TRACE=1` 可输出本次构建指纹和关键调用标识。[黑盒脚本](../../tests/acceptance_catalog.py)

### 官方插件启停

新 HOME 出现 `goal` 和 `composer-suggestions` 的版本化 manifest、Lua 文件及启用实例。一次推荐采样已到模型端，管理员在返回前停用插件，调用者收到空推荐。停用 Goal 后交办没有触发主动续跑；重启后两实例仍停用。此套使用受控模型验证派发和持久状态，真实供应商的问答质量与延迟由相应用例记录。
