# 用一个工作台运行和管理 Loom Harness

2026-11-24 产品目标已封板。用户打开官方插件的 `/webui/` 入口，按自身权限与 Agent 对话、管理资源、追查执行结果。Agent、插件和工具管理属于核心交付。其余范围包括模板与模型、Toolset 与连接、Session 与 Run、Goal 与审批、上下文及原文、事件投递与调度、HOME 配置与诊断。

管理界面与聊天操作共享实际资源及其服务端权限。用户可以在详情里核实创造者通过聊天修改的内容，也可以从该次 ToolCall 查到操作来源。通过 OI 接入的工具应出现在同一份目录里，让获授权的 Agent 直接使用 Service 的发布名。

2026-11-25 已在本机对照 DSH 和 Loom 的网页实测。用户可以在输入框找当前 Agent 的工具，在回复旁展开执行过程，在 Service 详情授予工具并进入对话。独立工具和插件可通过工具描述贡献输入建议。管理页的「与创造者讨论」把当前资源带入草稿，用户可以确认后再发送。[产品范围与验收](../../../spec/goals/webui.md) · [网页对照记录](../../../acceptance/webui-comparison.md)
