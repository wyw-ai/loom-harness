# 第一期云端 Agent 的 API 验收目标

一期交付后，普通用户能从模板创建 Agent，让它查询一份真实报告，并在重新连接同一 Session 后追问之前的结论。验收人既能读回两次交办的答复，也能用原文和 CI 记录确认答案出处与工具执行次数。[当前共识](../../../current/loom-agent/design.md#第一期交付目标) · [第一期完成标准](../../../../spec/goals/v1.md#phase-one-acceptance)

由 Codex 模拟用户与上层应用，使用对应身份操作同一服务的 HTTP API。日常会话、上下文与模型、Agent 与工具、投递与恢复四组用例共同覆盖本期能力。运行中断由测试部署制造，通过原 Run、ToolCall、实际交付或接收方计数验明结果。每项已确认且适用的场景须有实跑证据。具体请求、故障时点、通过条件和记录格式见[验收手册](../../../../acceptance/README.md)。

普通模板省略模型后的解析方式、Agent 向用户澄清时如何恢复原 Run、普通 Run 如何在重复调用时停止，分别保留在 A04、A05、A06。用例中给出的候选判据留待定版。
