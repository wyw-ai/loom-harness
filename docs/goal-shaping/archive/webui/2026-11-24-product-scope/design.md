# Loom Harness WebUI 产品目标封板快照

2026-11-24 确认官方页面插件提供一个覆盖整个 harness 的工作台。用户按身份管理 Agent、模板、模型、插件、工具、Toolset 与连接，使用会话与附件、分支与输入推荐，跟进 Run、Goal 与审批，并追溯上下文、系统指令、调用耗时、token 及 Note 原文。事件、订阅、调度、交付和 HOME 配置的生效情况也属于可查询或可操作的范围。

从 Agent 详情进入聊天，请获授权的创造者更改自身描述，再回到详情核实新值，是直接管理与对话管理共用资源的验收场景。跨仓验收从 OI 管理 Service 发布目标 Host 的动作，经自动生成的 Toolset、Agent 绑定和真实工具调用，追到 OI 侧的调用号。

界面以 Codex 的操作流程、布局、输入、焦点与动效为参考，保留 DSH 的聊天式管理思路。已有聊天原型，完整工作台的详细设计与实施待启动。未来开发按[封板目标和验收](../../../../spec/goals/webui.md)逐项检查能力覆盖。
